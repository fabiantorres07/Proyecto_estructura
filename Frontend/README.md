# Frontend Setup

This frontend is based on the TailAdmin React template.

## Credits
Original Creator: TailAdmin (https://tailadmin.com/)
GitHub: https://github.com/TailAdmin/tailadmin-free-tailwind-dashboard-template

## Installation

You'll need to install Node.js >=v14.16+.

1. Open your terminal and navigate to the `Frontend` directory.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.

Now, in the browser go to `http://localhost:5173`.

**For Production Build**
Run `npm run build`
The default build output directory is `/dist`.
